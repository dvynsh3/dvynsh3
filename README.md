# Hi, I'm Divyansh

I work across **strategy, the CEO's office and product management**. I take ambiguous problems from a rough hypothesis to working software.

I use code as a **product and discovery medium**: prototyping workflows, testing where users get stuck, and building small local-first tools that solve a real bottleneck without a login, a backend or a heavy setup.

---

## How I approach product

- **Start with the friction.** If a local, no-login flow does the job faster, I skip the backend.
- **Connect strategy to execution.** I turn goals and operating rhythms into concrete user flows and decision tools.
- **Ship early, then iterate.** A working version exposes edge cases faster than a spec does.

I build with AI coding tools. I write the problem statement and the requirements, make the product decisions, test the output, and keep the version history and changelogs in each repo.
